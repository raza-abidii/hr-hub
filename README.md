# My HR Hub

This repository contains the My HR Hub frontend application (Vite + React + TypeScript).

Quick start

```sh
git clone <YOUR_GIT_URL>
cd <YOUR_PROJECT_NAME>
npm install
npm run dev
```

Technologies

- Vite
- TypeScript
- React
- Tailwind CSS

To update dependencies and remove any removed packages run:

```sh
npm install
```
